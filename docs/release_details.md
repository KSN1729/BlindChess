# BlindChess Release v1 Details & Store Listing

## 1. Store Listing Draft

* **App Title**: BlindChess
* **Short Positioning**: BlindChess – Train Your Chess Visualization and Memory
* **Short Description**: 
  Play chess entirely blindfolded! BlindChess offers a full local 2-player pass-and-play chess experience, featuring a unique memory-training mode that hides pieces after a configurable move threshold. Test your spatial visualization skills, earn achievements, and track your daily streak!
* **Full Description**:
  Take your chess visualization to the next level with BlindChess, the ultimate offline memory-training tool. Designed for local 2-player pass-and-play matches, this app lets you play chess with standard chess rules (including castling, promotion, checkmate, stalemate, and en passant) while providing a configurable Blindfold Mode. 

  Choose between Easy, Medium, or Hard difficulty levels to control when pieces hide from the board. When pieces disappear, you must rely on your memory to tap and guess the true state of the board. Unlock achievements, build a daily streak, and track detailed stats on memory accuracy and match speeds.

* **Key Features**:
  - Full local 2-player pass-and-play chess with standard rules.
  - Blindfold Mode with 3 difficulty presets (Easy, Medium, Hard).
  - Tap-to-guess memory testing with live accuracy tracking and colored flash feedback.
  - 3-second Reveal peeks with a 10-move cooldown.
  - Daily Streak calendar tracking to build memory habits.
  - 7 unique achievement badges and lifetime statistics panel.
  - Custom board themes (Wood, Ocean, Slate) and Dark/Light Mode.
  - High-fidelity vector SVG pieces and standard match audio sound effects.
  - Fully offline, ad-free, and privacy-respecting.

## 3. Data Safety & Content Rating Documentation

* **Collection & Transmission**:
  - **No Accounts**: The app does not collect user registration details, emails, or names.
  - **No Network Permissions**: The app operates 100% locally and makes no network calls, transmits no data, and has no API integrations.
  - **No Analytics / Ads**: The app does not include third-party SDKs, tracking libraries, or advertising modules.
* **Storage**:
  - All configurations (board themes, volume, dark mode) and statistics (games, streaks, memory scores) are saved exclusively on the device using local `SharedPreferences`.
* **Content Rating**:
  - Suitable for all age groups (General Audiences). Contains no violence, mature content, or sensitive themes.
